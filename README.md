About The Project

This is a three-level adventure game made with Godot.

Level 1 - Training Parkour

The first level is an easy parkour training stage where players learn the basic controls and movement mechanics of the game.

Level 2 - Coin Collection Mission

In this level, the boss gives the player a mission to collect coins. The player must gather all required coins to unlock the path to the next level.

Level 3 - Memory Tower

The final challenge is a tower-based memory game. Players must remember patterns and make the correct choices to successfully reach the end of the tower.

Controls

-  Left / Right Arrow: Move
- Space: Jump
